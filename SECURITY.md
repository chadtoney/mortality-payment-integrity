# Security Policy

## Supported versions

This project is a demonstration and has no supported production release. Security fixes are applied to the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include personal data in a report. Use GitHub's private security advisory form for this repository:

https://github.com/chadtoney/mortality-payment-integrity/security/advisories/new

Include the affected component, reproduction steps using synthetic data, impact, and any suggested mitigation. Do not test against government systems or data without explicit authorization.
